## 🚀 Использование

```tsx
import { useNotification } from '../context/NotificationContext';

function MyComponent() {
  const { showNotification, showConfirm } = useNotification();

  // Toast-уведомление
  showNotification(
    'success',           // тип: 'success' | 'error' | 'warning' | 'info'
    'Успех!',           // заголовок
    'Операция выполнена', // сообщение (опционально)
    4000                // длительность в мс (опционально, по умолчанию 4000)
  );

  // Модальное окно подтверждения
  showConfirm({
    title: 'Удалить файл?',
    message: 'Это действие нельзя отменить.',
    type: 'danger',          // 'danger' | 'warning' | 'info'
    confirmText: 'Удалить',
    cancelText: 'Отмена',
    onConfirm: () => {
      // Действие при подтверждении
    },
    onCancel: () => {
      // Действие при отмене (опционально)
    },
  });
}
```

## 🎨 Дизайн-решения

### Цветовая палитра:
- **Success**: `emerald-500` → `green-600` (градиент)
- **Error**: `rose-500` → `red-600`
- **Warning**: `amber-500` → `orange-600`
- **Info**: `cyan-500` → `blue-600`

### Анимации:
- **slide-in-right**: Появление справа с bounce эффектом
- **scale-in**: Масштабирование с bounce
- **fade-in**: Плавное появление backdrop
- **progress-bar**: Линейное уменьшение прогресс-бара

### Эффекты:
- Box shadows с цветным glow
- Backdrop blur для глубины
- Gradient overlays для hover состояний
- Декоративные линии с градиентами
